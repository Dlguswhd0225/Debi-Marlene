# Debi & Marlene

데비는 D, 마를렌은 M으로 구분한 캐릭터 설정과 이미지 자료다. 이미지 파일은 열거나 디코딩하지 않고 기존 번호표와 바이트를 유지했다.

## 크랙에 적용

1. **스토리 설정 및 정보(5,000자)**: [스토리설정_정보_5000자.txt](스토리설정_정보_5000자.txt)의 본문 전체를 붙여 넣는다. 공백·줄바꿈 포함 정확히 5,000자다.
2. **유저노트(2,000자 이내)**: [유저노트_데비마를렌.txt](유저노트_데비마를렌.txt)의 본문 전체를 붙여 넣는다. 공백·줄바꿈 포함 1,998자다.
3. 두 파일은 각각 해당 칸에 적용한다. GitHub 파일 링크만 넣는 것으로 설정 본문이 자동 적용된다고 가정하지 않는다.

## 이미지 파일명

데비: D001.webp처럼 D+기존 세 자리 번호. 마를렌: M314.webp처럼 M+기존 세 자리 번호.
각 주체의 서술 바로 위에 본인 코드의 이미지를 출력한다. 둘이 같이 있으면 두 사람의 주체와 이미지를 각각 구분한다. 일상에서는 일상 이미지만 고르고, 무작위 선택은 같은 주체·같은 상황의 변형 안에서만 한다.

```text
![](https://raw.githubusercontent.com/Dlguswhd0225/Debi-Marlene/main/images/D154.webp)
데비|이야~! 오늘은 어디로 갈까?
![](https://raw.githubusercontent.com/Dlguswhd0225/Debi-Marlene/main/images/M564.webp)
마를렌|먼저 할 일부터 끝내.
```

공동 원본 247~249,311~313은 D/M 이름으로 각각 같은 바이트의 사본을 둔다. 311~313은 공동 대표·배너여서 일반 감정·행동 장면에는 쓰지 않는다. 서로 다른 원본은 476장, 실제 파일은 482개다. 제외한 원본 144장의 번호는 그대로 비워 둔다.
이전 숫자만 있는 파일명은 새 코드 파일명으로 교체했다. 이전 유저노트도 새 TXT로 교체해야 한다.
