# Debi & Marlene

데비·마를렌의 캐릭터 설정과 번호별 이미지 자료다. 기존 001~620 번호를 유지하며, 이번 업로드에서는 이미지를 열거나 디코딩하지 않고 파일 바이트와 기존 번호표를 사용했다.

## 파일

- `images/`: 제외 범위 144장을 뺀 이미지 476장. 기존 001~620 번호를 유지하므로 중간에 빈 번호가 있다.
- [캐릭터 기본 설정](settings/character.txt), [설정집](settings/book.md), [전투 추가 설정](settings/battle.txt)
- [유저노트용 기본 프롬프트](prompts/user-note.txt): 이미지 출력 규칙·전체 번호 범위·짧은 캐릭터 설정.
- [이미지 출력 규칙](prompts/image-rules.txt): 전체 이미지를 상황별로 묶은 간단판.
- [이미지 출력 규칙 상세판](prompts/image-rules-full.txt): 원본 키워드별 번호 구분.
- [유저노트 상세판](prompts/user-note-full.txt): 상세 이미지 규칙과 캐릭터 기본 설정.
- [이미지 번호표](image-index.md), [번호 대응 JSON](image-map.json)

## 이미지 주소

```text
![](https://raw.githubusercontent.com/Dlguswhd0225/Debi-Marlene/main/images/154.webp)
```

확장자는 `.webp`, 파일명은 001처럼 3자리다. 숫자 1을 선택했다면 `001.webp`를 사용한다.

데비 001~310, 마를렌 314~620. 247~249는 두 사람에게 공통 등록된 같은 이미지이므로 마를렌도 해당 장면에서 사용할 수 있다. 311~313은 대표 이미지·배너다. 283과 380은 CHARX에만 있던 별도 그림이다.

## 적용

TXT 파일의 본문을 유저노트에 넣어 사용한다. 파일 링크만 붙이는 것으로 본문이 자동 적용된다고 가정하지 않는다. 유저노트는 2,000자 이내다. 간단판과 상세판은 남은 476장의 번호만 포함하며, 목록에 있는 번호만 사용한다. 비슷한 원본 변형은 같은 큰 상황으로 묶었다. 상세 구분이 필요하면 상세판을 참조한다. 제외 번호는 `업로드_제외번호.txt`를 참고한다.

프로필과 이미지 출력 규칙은 텍스트다. RisuAI 전용 정규식·트리거를 크랙에서 자동 실행하는 기능은 포함하지 않는다. 크랙에서의 실제 출력 테스트는 수행하지 않았다.

이미지 순서와 내용은 바꾸지 않았다. 기존 정리에서 중복을 합친 620장 기준이며, 의미가 다른 파일을 새로 합치거나 재번호하지 않았다.
